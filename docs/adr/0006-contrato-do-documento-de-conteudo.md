# Contrato do Documento de Conteúdo

`current_data` é um documento JSON não nulo persistido integralmente em JSONB. Objetos e arrays podem ser arbitrariamente aninhados, inclusive vazios, e são retornados sem transformação de apresentação. A flexibilidade é estrutural: valores primitivos não podem aparecer diretamente em objetos ou arrays; devem estar dentro de um Campo Editável, em `value` ou `type`.

Um objeto que contenha `value` e `type` é um Campo Editável interpretado pelo dashboard externo; se contiver somente uma dessas chaves, é inválido. Os tipos iniciais são `string`, `text`, `number`, `boolean`, `url`, `hosted_file` e `external_file`. Para `hosted_file` e `external_file`, `value` contém diretamente a URL usada pela Aplicação Consumidora. A escolha do editor e a interpretação visual não pertencem ao LPData.
