# Labels de triagem

| Papel da skill | Label no tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A issue precisa de avaliação do mantenedor. |
| `needs-info` | `needs-info` | Aguarda informações de quem reportou. |
| `ready-for-agent` | `ready-for-agent` | Está especificada e pronta para um agente implementar. |
| `ready-for-human` | `ready-for-human` | Requer implementação humana. |
| `wontfix` | `wontfix` | Não será tratada. |

Use o valor da segunda coluna quando uma skill referir-se ao papel correspondente.
