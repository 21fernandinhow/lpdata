# Conteúdo para suas landing pages, sem republicar seu frontend

O LPData guarda o conteúdo e os assets das suas landing pages em uma API. Sua aplicação continua responsável pela apresentação; você atualiza o conteúdo sem alterar ou redistribuir o código do site.

## Para começar

A documentação orienta os donos de Aplicações Consumidoras na configuração e no uso da API do LPData.
