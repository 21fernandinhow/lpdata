# Gerencie e sirva o conteúdo das suas landing pages sem republicar seu frontend

O LPData é uma plataforma para **gerenciar e servir o conteúdo de landing pages por uma API**. Seu frontend cuida do layout; o LPData guarda os textos, links, números e arquivos que aparecem na página. Para mudar o conteúdo, você atualiza o LPData, sem alterar o código nem publicar o site de novo.

## Como funciona

<Steps>
  <Step title="Estruture o conteúdo">
    Crie uma Landing Page e envie seu Documento de Conteúdo: um JSON com a estrutura que seu frontend espera, em que cada valor é um Campo Editável com `value` e `type`.
  </Step>
  <Step title="Hospede seus arquivos">
    Envie imagens e outros arquivos como Assets e use as URLs retornadas no documento.
  </Step>
  <Step title="Sirva o conteúdo">
    Seu frontend busca o documento em `GET https://api.lpdata.io/landing_pages/<public_id>`, sem autenticação, e renderiza a página. Veja [Ler conteúdo publicado](/public-content).
  </Step>
  <Step title="Atualize quando quiser">
    Altere o documento pela API autenticada. A próxima leitura já entrega o novo conteúdo.
  </Step>
</Steps>

## O que o LPData faz e o que fica com você

| LPData | Sua aplicação |
| --- | --- |
| Armazena o Documento de Conteúdo de cada Landing Page | Define a estrutura do documento e como apresentá-lo |
| Hospeda os Assets usados no conteúdo | Renderiza layout, estilos e interações |
| Serve o conteúdo publicamente pelo Identificador Público | Busca o conteúdo e monta a página |
| Autentica quem gerencia o conteúdo | Oferece a experiência de edição, se precisar de uma |

O LPData é exclusivamente uma API: não tem editor visual nem hospeda páginas.
